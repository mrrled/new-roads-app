# Новые дороги

Android-приложение (Kotlin, Jetpack Compose), которое предлагает маршрут для прогулки
на заданное количество шагов (по умолчанию 10000) и старается прокладывать его по
дорогам, по которым пользователь ещё не ходил.

## Как это работает

- **Карта и дорожная сеть** — данные OpenStreetMap, полученные через публичный
  [Overpass API](https://overpass-api.de/) в радиусе вокруг текущего местоположения.
- **История хождений** — при каждой сгенерированной и пройденной прогулке участки дорог
  (рёбра графа OSM) сохраняются локально в базе Room (`visited_segments`). Хранится
  количество посещений и дата последнего визита.
- **Построение маршрута** (`routing/RouteGenerator.kt`) — приложение строит петлю нужной
  длины: сначала уходит от старта, на каждом перекрёстке взвешенно предпочитая рёбра,
  которых нет в истории посещений, затем возвращается к старту кратчайшим путём, где
  уже пройденные рёбра "дороже" непройденных. За счёт этого маршрут стремится пройти по
  новым дорогам, а не по уже знакомым.
- **Запись прогулки** — во время ходьбы фоновый сервис (`WalkTrackingService`) пишет
  GPS-точки, а по завершении маршрут сохраняется в историю, а его сегменты помечаются
  как пройденные.
- Все данные (история дорог и список прогулок) хранятся **только локально на
  устройстве**, сервер не используется.

## Стек

- Kotlin + Jetpack Compose (Material 3), Navigation Compose
- Room (локальная БД)
- osmdroid — отображение карты на основе OpenStreetMap
- Overpass API — получение графа дорог
- FusedLocationProviderClient (Google Play Services) — трекинг GPS

## Сборка проекта

1. Откройте папку проекта в Android Studio (Koala/Ladybug или новее).
2. При первом открытии Android Studio предложит создать/загрузить Gradle Wrapper —
   согласитесь, либо выполните `gradle wrapper --gradle-version 8.7`, если у вас
   локально установлен Gradle.
3. Дождитесь Gradle Sync, запустите на устройстве/эмуляторе с Google Play Services и
   доступом в интернет.
4. При первом запуске приложение запросит разрешения на геолокацию (и уведомления на
   Android 13+, они нужны для foreground-сервиса записи прогулки).

## Известные ограничения (MVP)

- Требуется интернет для запроса дорожного графа через Overpass API (офлайн-режим не
  реализован).
- Качество и покрытие данных зависит от полноты OpenStreetMap в конкретном районе.
- Каждый OSM way рассматривается как одно ребро графа (от первого до последнего узла),
  без разбиения по промежуточным перекрёсткам — для большинства городских районов этого
  достаточно, но в редких случаях это может огрублять граф.
- Длина шага зафиксирована как 0.75 м (примерно 10000 шагов ≈ 7.5 км); настройки длины
  шага в UI нет.
